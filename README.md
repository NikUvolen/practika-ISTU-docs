# Локальный запуск документации Diplodoc

Данное руководство описывает процесс локального запуска документации, созданной с использованием **Diplodoc** (`@diplodoc/documentation-template`).

---

## Требования

Перед началом работы убедитесь, что у вас установлены:

- **Node.js** версии **18 или 20 (LTS)**  
- Выполнить установку зависимостей
```bash
  npm install
```
- Установите пакет Diplodoc CLI, выполнив команду: 
```bash
  npm i @diplodoc/cli -g
```

---

## Сборка и запуск
Сборка выполняется с помощью инструмента Builder в командной строке.

Чтобы запустить сборку, выполните команду, указав обязательные ключи запуска:

    input, -i — путь до директории проекта.
    output, -o — путь до директории, предназначенной для выходных данных (статических HTML).

Пример:
```bash
  yfm -i ./input-folder -o ./output-folder
```
