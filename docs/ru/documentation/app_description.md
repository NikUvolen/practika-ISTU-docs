## 1. AUTHS — Аутентификация и профили

### Назначение
Модуль управления пользователями, авторизацией через Битрикс24 и ролевой моделью.

### Основные возможности
- Интеграция с Битрикс24 для единого входа  
- Автоматическая синхронизация с АИС ИрНИТУ  
- 5 типов пользователей:
  - студенты  
  - преподаватели  
  - представители компаний  
  - центр карьеры  
  - дирекция  
- Профили с расширенными данными  

### Модели
- **ExtendedUser** — расширенная модель пользователя Django с ролями  
- **Student** — профиль студента с привязкой к группе  
- **Teacher** — профиль преподавателя с привязкой к факультету  
- **CompanyRepresentativeProfile** — профиль представителя компании  

### Права доступа
- **IsStudent** — доступ только для студентов  
- **IsTeacher** — доступ только для преподавателей  
- **IsCareerCenterEmployee** — доступ только для сотрудников центра карьеры  
- **IsCompanyRepresentative** — проверка прав на компании  

### API и представления
- **CheckLogin** — проверка статуса аутентификации  
- **BitrixAuthView** — OAuth2-авторизация через Битрикс24  
- **StudentProfileView** — CRUD профиля студента  
- **TeacherProfileView** — CRUD профиля преподавателя  
- **CompanyRepresentativeProfileView** — CRUD профиля представителя компании  

### Интеграции
- Синхронизация данных студентов из АИС при первом входе  
- Автоматическое создание профилей на основе данных Битрикс24

## 2. ADMINISTRATION — Административные функции

### Назначение
Модуль для административных панелей дирекции и центра карьеры.

### Основные возможности
- Генерация Excel-отчетов по практике учебных групп  
- Создание индивидуальных заданий в формате Word  
- Административные панели с группировкой данных  
- Экспорт документов для бюрократических процессов  

### Компоненты
- **DirectoratePageService** — обработка данных для страницы дирекции  
- **CareerCenterPageService** — обработка данных для страницы центра карьеры  
- **GroupDecreeExport** — генерация Excel-приказов по практике  
- **IndividualTaskFiller** — заполнение Word-шаблонов индивидуальных заданий  

### API и представления
- **DirectoratePage** — API для страницы дирекции  
- **CareerCenterPage** — API для страницы центра карьеры  
- **ExportGroupPracticeInfo** — выгрузка Excel-файла по группе  
- **ExportIndividualTask** — выгрузка индивидуального задания  

### Шаблоны документов
- Excel-шаблон `group_decree.xlsx` для приказов  
- Word-шаблон `individual_task_template.docx` для индивидуальных заданий  

### Запросы и оптимизация
- Сложные SQL-запросы с группировкой по факультетам, специальностям и группам  
- Оптимизированные запросы для отчетности

## 3. INTERNSHIP — Управление практиками

### Назначение
Модуль управления практиками, заявками студентов и отчетами.

### Основные возможности
- Каталог практик от компаний  
- Система заявок студентов на практику  
- Назначение руководителей от университета  
- Управление статусами прохождения практики  
- Система отчетности по практике  

### Модели
- **Internship** — описание практики (тема, компания, требуемые навыки)  
- **InternshipRequest** — заявка студента на практику  
- **StudentsInternship** — связь студент–практика–преподаватель  
- **StudentsInternshipReport** — отчет по практике  
- **Skill** — навыки, требуемые для практики  
- **PracticeType** — типы практик (ВКР, производственная, НИОКР)  

### Бизнес-логика
- У одного студента может быть только одна одобренная заявка  
- При одобрении заявки все остальные автоматически отклоняются  
- Проверка соответствия специальности студента требованиям практики  

### API и представления
- **InternshipViewSet** — CRUD-операции для практик  
- **InternshipRequestListCreateAPIView** — создание и просмотр заявок  
- **InternshipRequestApproveAPIView** — одобрение заявок  
- **StudentsInternshipViewSet** — управление связями студент–практика  

### Сервисы
- **InternshipRequestService** — бизнес-логика обработки и одобрения заявок

## 4. COMPANIES — Управление компаниями

### Назначение
Модуль управления компаниями-партнерами, договорами и контактной информацией.

### Основные возможности
- Каталог компаний-партнеров ИрНИТУ  
- Управление договорами о сотрудничестве  
- Хранение контактов представителей компаний  
- Интеграция с АИС для синхронизации договоров  

### Модели
- **Company** — компания-партнер  
- **Contact** — контактное лицо компании  
- **Agreement** — договор о сотрудничестве  
- **ContactType** — тип контакта (Telegram, email, телефон)  

### Права доступа
- Представители компаний могут редактировать только свои данные  
- Сотрудники центра карьеры могут создавать компании и договоры  
- Все аутентифицированные пользователи имеют доступ на просмотр  

### API и представления
- **CompanyViewSet** — CRUD для компаний с учетом прав доступа  
- **ContactViewSet** — управление контактами  
- **create_with_agreement** — endpoint для создания компании вместе с договором  

### Интеграции
- Автоматическая синхронизация договоров из АИС командой `update_agreements`

## 5. UNIVERSITY — Структура университета

### Назначение
Модуль хранения иерархической структуры университета.

### Основные возможности
- Иерархия:  
  **Факультет → Специальность → Направление → Поток → Группа**  
- Интеграция с АИС по идентификаторам записей  
- Хранение метаданных по учебным группам (годы, сроки практики)  

### Модели
- **Faculty** — институт / факультет  
- **Speciality** — специальность с уровнем образования  
- **Direction** — направление подготовки  
- **Stream** — поток (год поступления + направление)  
- **StudentGroup** — учебная группа  
- **StudentGroupYearMeta** — метаданные группы по годам  

### Утилиты
- `StudentGroup.get_by_name()` — парсинг имени группы по шаблону `НАПР-21-1`  
- Автоматическое определение потока по году поступления  

### API и представления
- ViewSet для каждой модели с полным CRUD  
- Иерархическое отображение структуры университета

## 6. COMMENTS — Система комментариев

### Назначение
Модуль для комментирования заявок на практику и отчетов студентов.

### Основные возможности
- Универсальная система комментариев  
- Привязка комментариев к заявкам и отчетам  
- Хронология обсуждений с временными метками  

### Модели
- **Comment** — базовый комментарий (автор, текст, дата)  
- **InternshipComment** — комментарии к заявкам на практику  
- **StudentsInternshipReportComment** — комментарии к отчетам по практике  

### Архитектура
- Отдельная модель комментариев для возможности расширения  
- Связь с сущностями через промежуточные модели

## 7. CORE — Общие утилиты и интеграции

### Назначение
Общие компоненты, используемые всеми модулями системы.

### Excel
- **ExcelTemplate** — система шаблонов Excel-документов  
- **CustomWorkSheet** — оптимизированная работа с большими Excel-файлами  
- **ExcelWorkSheet** — абстракция для Excel-листов  

### Интеграция с АИС
- **AisFetcher** — клиент для работы с API АИС ИрНИТУ  
- Поддержка различных endpoint’ов АИС  

### Утилиты
- **Dataloader** — выполнение сложных SQL-запросов через Django ORM  

### Конфигурация
- Настройки подключения к АИС в `settings.py`  
- Конфигурация Excel-ячеек в `cells_config.py`
