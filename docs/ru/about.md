# Описание проекта

**Цель проекта** - организация комплексного подхода к летней практике студентов ИРНИТУ и организации безбумажного взаимодействия между подразделениями ИРНИТУ с привлечением сторонних организаций.


{% note warning %}

Документация находится в процессе написания.

{% endnote %}

{% note info %}

Проект доступен по ссылке [job.istu.edu](https://job.istu.edu/out/)

{% endnote %}

## Общий обзор

Проект представляет собой **REST API**, предназначенный для управления процессами прохождения практики студентами, взаимодействия с компаниями и административного контроля со стороны университета.

Архитектура построена по **модульному принципу**, где каждый бизнес-домен вынесен в отдельное Django-приложение.

Основные принципы:
- разделение ответственности по доменам
- слабая связанность модулей
- единый API-шлюз
- централизованная авторизация и контроль доступа

## Рабочий стек
- Бэкенд: `Django 5.2`, `Django REST Framework`
- Фронтенд: `Vue 3`
- БД: `PostgreSQL 17.4`
- Веб-сервер: `NGinx 1.22.1`
- Деплой: `Docker`, `Docker Compose`
- Документация: `DRF Spectacular (Swagger/ReDoc)`
- Итнеграции: 
    - `Bitrix24 API` - для аутентификации через ИрНИТУ 
    - `Внутреннее API ИрНИТУ (АИС)` (получение данных о студентах, договорах и т.д.)
